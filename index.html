Map extensions for Tableau

Static pages for Tableau viz extensions. Add a .trex file from the Marks card in Tableau (Add Extension, Access Local Extensions).

  • map-studio.trex: layered map (shapes, symbols, pies, flow arcs; flat or globe)
  • routes-arcs.trex: flow arcs
  • pie-symbol-map.trex: pie charts as symbols
  • symbol-map.trex: choice of symbol
